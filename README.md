# Task Tracker REST API

## Description

A REST API for managing tasks using Flask and PostgreSQL.

## Technologies Used

- Python
- Flask
- PostgreSQL
- Psycopg
- REST API

## Features

- Create Task
- Get All Tasks
- Get Task by ID
- Update Task
- Delete Task
- Filter Tasks by Category
- Search Tasks
- Search Tasks by Category
- Input Validation
- Error Handling
